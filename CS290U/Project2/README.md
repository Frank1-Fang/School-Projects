This directory contains all the Python scripts that I have manually implemented.
- `evaluate_matches.py` Evaluates feature matching results stored as `.npz` files by computing RANSAC-based fundamental matrix consistency, inlier ratios, and mean epipolar errors for quantitative comparison across different methods.
- `generate_testset_from_colmap.py` Generates a structured JSON test set from COLMAP outputs by reading camera intrinsics and image poses, computing relative rotations and translations for selected image pairs, and exporting them for downstream reconstruction or localization evaluation.
- `my_run_superglue.py` Runs a complete SuperGlue-based feature matching and pose evaluation pipeline: loads image pairs and ground-truth poses from a JSON test set, performs SuperPoint+SuperGlue matching, estimates essential matrices and relative poses, computes rotation/translation errors, saves visualizations, and summarizes results in CSV format.
- `run_mast3r_pair.py` Performs pairwise image matching using the MASt3R model: loads two input images, computes dense feature correspondences, saves keypoint pairs as `.npz`, and visualizes match lines with color-coded connections for qualitative analysis.
- `run_mast3r_recon.py` Performs pairwise 3D reconstruction using MASt3R and COLMAP poses: extracts dense feature matches between two images, computes the relative camera transformation, triangulates 3D points via a simplified DLT method, and visualizes multi-view projections (XY, XZ, YZ, 3D) for reconstruction analysis.
- `run_vggt_pair.py` Performs pairwise feature tracking and visualization using the VGGT model: loads two input images, extracts visual tokens, tracks sampled points across frames, saves matched keypoints as `.npz`, and generates a color-coded match visualization to illustrate VGGT’s correspondence estimation.
- `visualize_colmap_multiple_angles.py` Visualizes COLMAP-generated sparse reconstructions from multiple viewpoints: reads 3D points and camera poses, renders both point clouds and camera centers in 3D, and saves four perspective images (rotated around the scene) for a comprehensive spatial overview.
- `visualize_colmap_sparse.py` Visualizes a single-view 3D point cloud and camera distribution from COLMAP’s sparse reconstruction by reading `points3D.txt` and `images.txt`, rendering both the reconstructed points and estimated camera centers in 3D, and saving a high-resolution overview image.
- `visualize_vggt_recon.py` Visualizes VGGT 3D reconstruction outputs exported from COLMAP’s `sparse_txt` format: reads `points3D.txt`, filters valid 3D points, and generates multiple projection views (XY, XZ, YZ) and a 3D perspective visualization, saving all rendered figures for report inclusion.
